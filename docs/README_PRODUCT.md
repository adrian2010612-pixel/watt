# WHAT IF v2

A redesigned front-end prototype based on the product/investor review.

## Major upgrades
- Daily What If
- Branching timeline decisions
- Butterfly-effect consequences
- Predictions + community baseline
- Quizzes + XP
- Levels/achievements
- Saves + profile progression
- Scenario Lab
- Evidence labels: FACT / PLAUSIBLE / POSSIBLE / SPECULATIVE
- Source layer
- Full-site search
- Dark mode
- Mobile menu
- Cookie notice
- Back-to-top
- Local browser persistence
- Share interaction
- Focused Sports/History-first content direction
- Removed unrelated IdeaHub, SkillBridge and computer-store sections
- Production architecture and product brief included in `/docs`

## Run
Open `index.html` in a browser or deploy the folder to any static host. No build step is required for this prototype.

## Important
This is a front-end prototype. Scenario Lab is intentionally a simulated AI experience. A production release needs authenticated server state, PostgreSQL, source/claim verification, moderation, analytics and an AI orchestration layer.

## Product proof to target
The most important behaviour to measure is **Weekly Completed Timelines**, alongside D1/D7/D30 retention, predictions per user, shares per user, organic acquisition and premium conversion.
